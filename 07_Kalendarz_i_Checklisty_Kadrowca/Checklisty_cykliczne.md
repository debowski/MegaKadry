# Checklisty cykliczne obowiązków kadrowych (ZGKiM w Orzeszu)

Jeden zbiór list kontrolnych do codziennej, tygodniowej, miesięcznej, kwartalnej, rocznej i końcoworocznej pracy kadrowej. Każdy wiersz zawiera: zadanie, termin, podstawę, odpowiedzialność, dokument wynikowy i sposób potwierdzenia wykonania.

| Metryka dokumentu | Wartość |
| --- | --- |
| Nazwa dokumentu | Checklisty cykliczne obowiązków kadrowych |
| Wersja | 1.0 |
| Data opracowania | 2026-11-25 |
| Data ostatniej weryfikacji | 2026-11-25 |
| Odpowiedzialność | Specjalista ds. kadr; nadzór: Dyrektor Zakładu (**DO UZUPEŁNIENIA PRZEZ PRACODAWCĘ**) |
| Status | **ROBOCZY** |

**Statusy w tabelach:** `W` – wykonano, `NW` – nie wykonano, `ND` – nie dotyczy, `WY` – wymaga wyjaśnienia. Potwierdzenie = data i inicjały osoby, która wykonała zadanie (nie wpisuj danych osobowych pracowników).

> **Ważne:** obowiązki zależne od zdarzenia (zatrudnienie, zmiana danych, ustanie stosunku pracy, wniosek urlopowy, wypadek) **nie mają stałego dnia miesiąca**. Są zebrane osobno na końcu tego dokumentu i w [`Kalendarzu obowiązków`](Kalendarz_obowiazkow_kadrowych_roczny_i_miesieczny.md) w części „Obowiązki bieżące”. Terminy sztywne (np. 5., 15., 20. dnia miesiąca) dotyczą wyłącznie rozliczeń z ZUS, PPK, US i PFRON.
