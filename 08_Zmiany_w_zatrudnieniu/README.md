# Zmiany w zatrudnieniu

Procedury i checklista dla sytuacji, w których zmieniają się warunki umowy o pracę.

Status: **ROBOCZY / DO WERYFIKACJI** · Data weryfikacji: **2026-11-25**

| Dokument | Kiedy użyć |
| --- | --- |
| [`Procedura_zmian_w_zatrudnieniu.md`](Procedura_zmian_w_zatrudnieniu.md) | Główna procedura z osobnymi sekcjami: zmiana stanowiska, wynagrodzenia, wymiaru etatu, miejsca pracy, przedłużenie umowy, powierzenie innej pracy i zmiana danych |
| [`Checklista_zmiany_zatrudnienia.md`](Checklista_zmiany_zatrudnienia.md) | Kontrola kompletności i poprawności dokumentów |

Każda zmiana wymaga ustalenia: podstawy (zgoda stron, aneks, powierzenie innej pracy itd.), zakresu zmiany, daty wejścia w życie, dokumentu wynikowego oraz aktualizacji informacji o warunkach zatrudnienia (art. 29 § 3³ KP) i danych przekazywanych do płac.

Typowy błąd: późniejsze wpisywanie zmiany do ewidencji bez aneksu lub bez potwierdzenia przez pracownika.
