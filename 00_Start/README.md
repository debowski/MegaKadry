# 00_Start — punkt wejścia dla nowego kadrowca

Ten folder jest **pierwszym miejscem, które warto otworzyć**, jeśli zaczynasz pracę w kadrach Zakładu Gospodarki Komunalnej i Mieszkaniowej w Orzeszu (ZGKiM). Zawiera krótkie, praktyczne przewodniki. Szczegółowe procedury i wzory znajdują się w pozostałych folderach repozytorium.

Dane identyfikacyjne pracodawcy (nazwa, adres, Dyrektor, statut) są zweryfikowane i znajdują się w pliku [`../00_Dane_pracodawcy_ZGKiM_Orzesze.md`](../00_Dane_pracodawcy_ZGKiM_Orzesze.md). Wszystko, czego nie udało się potwierdzić, oznaczono jako **DO UZUPEŁNIENIA PRZEZ PRACODAWCĘ**.

## Jak czytać dokumenty w tym folderze

1. Najpierw przeczytaj **Instrukcję dla nowego kadrowca** — wyjaśnia, jak poruszać się po repozytorium.
2. Potem wybierz **Mapę obowiązków** albo **Najczęstsze zadania** — zależnie od tego, czy potrzebujesz obrazu całości, czy gotowej instrukcji.
3. W razie wątpliwości sprawdź **Słownik pojęć**.
4. Jeśli dokument, który chcesz stosować, zależy od ustaleń Zakładu (regulamin, system czasu pracy, instytucja PPK), zajrzyj do **Konfiguracji ZGKiM Orzesze**.

> **Ważne:** dokumenty mają status **ROBOCZY / DO WERYFIKACJI**. Nie oznaczaj ich jako zatwierdzonych przez ZGKiM bez potwierdzenia przez pracodawcę. Do repozytorium nie wpisuj rzeczywistych danych pracowników — wzory zawierają wyłącznie pola w nawiasach kwadratowych do uzupełnienia w środowisku pracy.
