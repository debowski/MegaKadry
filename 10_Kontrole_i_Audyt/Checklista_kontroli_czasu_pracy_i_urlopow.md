# Checklista kontroli czasu pracy i urlopów

*Dokument ROBOCZY — do użycia z [Instrukcją kontroli wewnętrznej](Instrukcja_kontroli_wewnetrznej.md). Nie zawiera danych osobowych.*

**Sposób wypełniania:** w kolumnie „Status" wpisz dokładnie jeden z czterech zapisów: **wykonano** / **nie wykonano** / **nie dotyczy** / **wymaga wyjaśnienia**. „Nie dotyczy" zawsze uzasadnij (np. „pracownik nie objęty systemem zmianowym"). „Wymaga wyjaśnienia" oznacza, że decyzję podejmuje Dyrektor, dział płac lub obsługa prawna.

> **Uwaga wstępna:** nie zakładaj, że wszyscy pracownicy ZGKiM pracują w jednym systemie czasu pracy. Pracownicy administracyjni, kierowcy, konserwatorzy i pracownicy zmianowi mogą być objęci różnymi systemami i okresami rozliczeniowymi. Stan faktyczny jest **DO UZUPEŁNIENIA PRZEZ PRACODAWCĘ** (regulamin pracy / obwieszczenie).

| 1.2 | Zakres danych | Ewidencja zawiera: liczbę godzin przepracowanych, godzinę rozpoczęcia i zakończenia pracy, godziny w porze nocnej, godziny nadliczbowe, dni wolne z tytułem, godziny dyżuru z miejscem jego pełnienia, rodzaj i wymiar zwolnień od pracy, inne usprawiedliwione i nieusprawiedliwione nieobecności (§ 6 pkt 1 rozporządzenia w sprawie dokumentacji pracowniczej). | Ewidencja |  |  |
| 1.3 | System czasu pracy | Dla każdego pracownika wskazany system czasu pracy i okres rozliczeniowy, zgodnie z regulaminem pracy / obwieszczeniem. | Regulamin / obwieszczenie |  |  |
| 1.4 | Rozkład czasu pracy | Rozkład ustalony i podany do wiadomości pracowników; zmiany rozkładu wprowadzane z zachowaniem terminów. | Rozkład / ogłoszenie |  |  |
| 1.5 | Podpisy / potwierdzenia | Ewidencja papierowa potwierdzona przez pracownika i osobę odpowiedzialną; ewidencja elektroniczna ma zapisany mechanizm potwierdzania. | Podpis / log |  |  |
| 1.6 | Zamknięcie okresu | Ewidencja zamknięta po upływie okresu rozliczeniowego przed przekazaniem danych do płac. | Data zamknięcia |  |  |
| 1.7 | Praca w dniu wolnym | W ewidencji odnotowano dzień wolny udzielony w zamian za pracę w dniu wolnym wynikającym z rozkładu (art. 151³ KP) — termin uzgodnienia z pracownikiem. | Wniosek / uzgodnienie |  |  |
| 1.8 | Ewidencja dla kierowców | Dla kierowców sprawdzono dodatkowe ewidencje wynikające z odrębnych przepisów (czas jazdy, odpoczynki) — **jeśli dotyczy**. | Ewidencja kierowcy |  |  |

## 2. Nadgodziny i praca w dni wolne

| Lp. | Element kontroli | Co sprawdzić | Dowód | Status | Uwagi |
| --- | --- | --- | --- | --- | --- |
| 2.1 | Polecenie nadgodzin | Praca w godzinach nadliczbowych polecona przez pracodawcę / przełożonego; polecenie udokumentowane. | Polecenie |  |  |
| 2.2 | Przyczyny | Każda nadgodzina ma wpisaną przyczynę (szczególna potrzeba / koniczność), zgodnie z art. 151 KP. | Ewidencja / polecenie |  |  |
| 2.3 | Limity | Dobowy i tygodniowy wymiar czasu pracy z uwzględnieniem nadgodzin nie przekracza limitów z art. 151 KP (z wyjątkami art. 151² i art. 151⁴). | Ewidencja |  |  |
| 2.4 | Zgody | Nadgodziny u pracownika opiekującego się dzieckiem do 8. roku życia wymagały zgody (art. 178 § 2 KP); sprawdzono zgodę w aktach. | Zgoda w części B |  |  |
| 2.5 | Dzień wolny zamiast dodatku | Rozliczenie nadgodzin: dzień wolny udzielony w terminie lub dodatek wypłacony zgodnie z art. 151² KP — zgodnie z zasadami przyjętymi u pracodawcy. | Ewidencja / lista płac |  |  |
| 2.6 | Praca w niedzielę i święta | Spełniono wymogi art. 151¹–151¹¹ KP; udzielono dnia wolnego w zamian albo wypłacono dodatek. | Ewidencja / polecenie |  |  |
| 2.7 | Przekazywanie danych | Liczba nadgodzin przekazana do działu płac w terminie wynikającym z regulaminu/ustaleń wewnętrznych. | Pismo / plik |  |  |

## 3. Dyżur i gotowość do usuwania awarii

| Lp. | Element kontroli | Co sprawdzić | Dowód | Status | Uwagi |
| --- | --- | --- | --- | --- | --- |
| 3.1 | Podstawa dyżuru | Dyżur wynika z umowy, regulaminu lub porozumienia i jest udokumentowany poleceniem. | Polecenie dyżuru |  |  |
| 3.2 | Ewidencja dyżuru | W ewidencji zapisano liczbę godzin dyżuru, godzinę rozpoczęcia i zakończenia oraz miejsce pełnienia (§ 6 pkt 1 rozporządzenia). | Ewidencja |  |  |
| 3.3 | Gotowość awaryjna | Jeśli w ZGKiM stosowana jest gotowość do usuwania awarii — sprawdzono zasady jej rozliczania w regulaminie i przekazanie danych do płac. | Regulamin / notatka |  |  |
| 3.4 | Czas pracy w trakcie dyżuru | Godziny faktycznej pracy w trakcie dyżuru wliczono do czasu pracy i rozliczono jako nadgodziny, jeśli przekroczyły normę. | Ewidencja |  |  |
| 3.5 | Dzień wolny / dodatek | Rozliczenie zgodne z art. 151² i art. 151⁵ KP. | Lista płac |  |  |

## 4. Urlopy wypoczynkowe

| Lp. | Element kontroli | Co sprawdzić | Dowód | Status | Uwagi |
| --- | --- | --- | --- | --- | --- |
| 4.1 | Wymiar urlopu | Wymiar ustalony na podstawie stażu pracy (20 lub 26 dni) z uwzględnieniem dodatkowego wymiaru dla pracowników z niepełnosprawnością — **jeśli dotyczy**. | Decyzja / ewidencja |  |  |
| 4.2 | Staż | Dokumenty potwierdzające staż (świadectwa pracy, zaświadczenia) w aktach lub w dokumentacji płacowej. | Świadectwa / zaświadczenia |  |  |
| 4.3 | Plan urlopów | Plan urlopów ustalony na dany rok i podany do wiadomości; uwzględnia preferencje pracowników w miarę możliwości. | Plan urlopów |  |  |
| 4.4 | Wniosek urlopowy | Wniosek złożony z wyprzedzeniem wynikającym z regulaminu; zatwierdzony przez przełożonego. | Wniosek |  |  |
| 4.5 | Termin udzielenia | Urlop udzielony w roku, w którym pracownik nabył do niego prawo. | Ewidencja urlopów |  |  |
| 4.6 | Urlop na żądanie | Wniosek złożony najpóźniej w dniu rozpoczęcia urlopu; pracodawca udzielił go bez odmowy (art. 167² KP). | Wniosek |  |  |
| 4.7 | Urlop zaległy | Urlop z poprzedniego roku udzielony **najpóźniej do 30 września** (art. 168 KP). | Ewidencja / plan |  |  |
| 4.8 | Przyczyna zaległości | Jeśli urlop zaległy nie został udzielony — udokumentowana przyczyna i decyzja Dyrektora; ryzyko wykroczenia przeciwko prawom pracowniczym. | Notatka |  |  |
| 4.9 | Ekwiwalent | Ekwiwalent za niewykorzystany urlop rozliczony przy ustaniu zatrudnienia (art. 171 KP); wyjątek z art. 171 § 3 KP udokumentowany. | Rozliczenie |  |  |
| 4.10 | Części urlopu | Podział urlopu na części i zasady udzielania części niekrótszej niż 14 dni — zgodnie z art. 162 KP i regulaminem. | Wniosek / ewidencja |  |  |

## 5. Inne zwolnienia i nieobecności

| Lp. | Element kontroli | Co sprawdzić | Dowód | Status | Uwagi |
| --- | --- | --- | --- | --- | --- |
| 5.1 | Zwolnienia od pracy | W ewidencji wpisano rodzaj i wymiar zwolnień (siła wyższa, opieka nad dzieckiem do 14 lat, urlop opiekuńczy) z właściwym tytułem. | Ewidencja / wnioski |  |  |
| 5.2 | Nieobecności | Usprawiedliwione i nieusprawiedliwione nieobecności oznaczone odrębnie. | Ewidencja |  |  |
| 5.3 | Zwolnienie lekarskie | Wpis do ewidencji na podstawie zwolnienia lekarskiego (ZUS L4 / e-ZLA); dane o przyczynie nieobecności nie są rozpowszechniane. | e-ZLA / ewidencja |  |  |
| 5.4 | Dane o zdrowiu | Dane o stanie zdrowia przetwarzane wyłącznie w zakresie niezbędnym i na właściwej podstawie — **nie na podstawie zgody pracownika** jako podstawy wyłączającej z art. 9 ust. 2 RODO. | Klauzula / procedura |  |  |
| 5.5 | Przekazanie do płac | Nieobecności i zwolnienia przekazane do działu płac w terminie umożliwiającym prawidłowe rozliczenie. | Pismo / plik |  |  |
